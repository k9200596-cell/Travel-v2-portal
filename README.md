# K-TRAVEL PICKS v12 — 사용 및 수동 배포 안내

생성일: 2026-10-16 (한국 시간)

## 주요 개선

- 기존 v11 `index.html`을 기반으로 관광지·일정·경비·저장 코드를 유지하면서 확장.
- Wikimedia Commons의 사진 설명 페이지를 확인해 실제 관광지 사진 9장 추가.
- 총 12개 도시, 60개 관광지, 사진 출처 32장(관광지 28곳에 사진 연결). 기존 23장 메타데이터는 v11에서 인계.
- 도톤보리·도쿄 스카이트리·지우펀 등 동일 관광지에 사진이 여러 장이면 상세보기에서 사진 전환 가능.
- 관광지 목록에 `📷 사진 출처 확인된 곳만` 필터 추가.
- 사진 실패 시 `사진 연결 실패 · 대체 이미지` 표시; 모바일 카드와 상세 모달에서 명확히 구분.
- 여행계획 JSON 백업 포맷 버전 표시를 v12로 변경. 기존 저장 데이터 스키마는 유지.
- 상단 맨 오른쪽 버전 배지 v12.

## 포함 파일

- `index.html`: 단일 HTML/CSS/JavaScript 웹 앱. GitHub Pages에서 직접 실행.
- `PHOTO_SOURCES.json`: 사진별 원본 파일 페이지·저작자·라이선스·촬영일·확인일·표시용 썸네일 URL.
- `TEST_REPORT.json`: 자동 기능 테스트 결과 및 미검증 사항.
- `README.md`: 이 안내.

## 실행

1. 압축을 풀고 `index.html`을 Chrome 또는 Edge에서 엽니다.
2. `여행지 찾기` → 도시 선택 → 관광지 상세정보 → 일정에 추가 → 항공·숙박·현지 경비 입력.
3. `현재여행 브라우저에 저장`으로 저장하고 `파일로 저장`으로 JSON 백업합니다.
4. 사진은 외부 Wikimedia 서버에서 불러오므로 인터넷 연결이 필요합니다.

## GitHub 수동 배포 (자동 업로드·배포 없음)

1. 본인 GitHub 저장소 `k9200596-cell/Travel_v2`의 `main` 브랜치를 엽니다.
2. 현재 `index.html`을 다운로드해 별도 보관합니다.
3. ZIP의 `index.html`을 저장소 루트의 `index.html`로 교체합니다.
4. `Commit changes`를 눌러 변경사항을 확정합니다.
5. GitHub Pages 설정을 확인한 후 본인 사이트에서 v12 배지, 여행 일정, 사진, 경비, 저장 기능을 직접 확인합니다.

## 사진 라이선스 및 검증 범위

- 새로 추가한 9장은 Wikimedia Commons의 개별 파일 페이지에서 실제 장소·촬영일·저작자·라이선스를 확인했습니다.
- v11에서 인계한 23장 모두를 이번 실행에서 다시 검증하지는 않았습니다.
- 일부 새 사진의 썸네일을 웹 검색 도구로 확인했지만, 전체 32장의 실제 브라우저 이미지 로딩 및 GitHub Pages 실서비스 작동은 검증하지 않았습니다.
- CC BY 및 CC BY-SA는 저작자·원본·라이선스 표시 의무가 있으며, 수정·재배포 시 각 사진의 조건을 따르세요.
- 이미지 파일은 ZIP에 포함하지 않았습니다. 로딩 실패 시 SVG 대체 이미지가 표시됩니다.
- 여행사 사이트의 이미지나 코드를 복제하지 않았습니다.
- 유료 API를 사용하지 않았으며 GitHub에 업로드하거나 배포하지 않았습니다.
