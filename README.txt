K-TRAVEL PICKS / Travel_v2 v18 (2026-10-16)
========================================

[파일]
- index.html : 전체 HTML/CSS/JavaScript 소스. GitHub Pages에서는 저장소 최상위의 index.html로 사용합니다.
- photo_sources.json : 사진 74장 출처 메타데이터 (원본 URL, 저작자, 라이선스, 촬영일, 확인일)
- photo_sources.csv : 사진 74장 점검표 (Excel 열기 가능, UTF-8 BOM)
- test_report.json : 실제 수행한 정적/JS 함수 검사 38건 결과 및 미검증 항목

[v17 -> v18 변경]
1) 막탄 해변 사진 1장 추가: 2017년 막탄 블루워터스 해변 (CC BY-SA 4.0, Øyvind Holmstad).
   https://commons.wikimedia.org/wiki/File:BB_Blue_Waters_Mactan_beach_2.jpg
   해당 리조트 해변을 촬영한 것이며 막탄섬 전체 해변을 대표하지 않습니다.
2) 홍콩 몽콕 야시장 사진 1장 추가: 2015년 통초이 거리 야시장 (CC BY 3.0, Sakaori).
   https://commons.wikimedia.org/wiki/File:Tung_Choi_Street_market_of_summer_night.JPG
   과거 사진으로 표시하며 현재 노점 운영을 보장하지 않습니다.
3) 기존 사진 3장(2010 막탄 해변, 2014 몽콕 야시장, 2008 혼총 곶) 원본 설명·라이선스 재확인.
4) 사진 총 74장, 관광지 60곳 출처 기록 유지. 신규 2장과 재검증 3장 외 69장은 기존 기록 계승.
5) 날짜별 여행 일정에 이동·여유시간 0/15/30/60분 선택, 시간 겹침 경고 추가.
   계산식: 이전 관광지 시작시각 + 권장 체류시간 + 설정 여유시간 > 다음 시작시각이면 경고.
   사용자 직접 입력 일정의 권장 체류시간은 60분으로 가정. 실제 지도 이동시간은 계산하지 않습니다.
6) 이동·여유시간 설정을 여행 JSON 저장/복원에 포함(schema 6). 기존 schema 5 파일은 30분 기본값으로 열립니다.
7) 모바일 화면용 관광지·일정·경비·준비 바로가기 추가. 홈페이지 우측 상단 v18 표시.
8) 기존 관광지/일정/경비/브라우저 저장/JSON 백업·복원/사진 갤러리/필터 코드 유지.

[검증 범위]
- HTML 구조/출처 메타데이터/JavaScript 구문 및 핵심 계산 함수 검사 38건 통과.
- 실제 브라우저 종단 간 검증은 수행하지 못했습니다. 작업 환경의 관리형 Chromium 정책이 file://와 localhost 탐색을 차단합니다.
- 모바일 레이아웃의 실제 화면 렌더링, 외부 사진 74장의 실시간 로딩, 실제 사이트 저장·복원은 추가 확인이 필요합니다.
- 사진은 ZIP에 포함하지 않고 Wikimedia Commons 외부 URL로 로딩합니다. 오류 시 명시적인 SVG 대체 이미지가 표시됩니다.
- 무료 라이선스도 저작자 표시 등 개별 조건이 있습니다. 원본 페이지에서 조건을 확인하세요.
- 여행 정보·교통·입장료·영업시간은 실시간 API 기반이 아닙니다.
- 유료 API 미사용. GitHub 업로드/배포 수행하지 않음.
